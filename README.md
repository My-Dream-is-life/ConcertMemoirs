# Concert Memoirs

## Packages

   - ### dependencies:

      - [Ant Design](https://ant.design/): React UI library
      - [clsx](https://www.npmjs.com/package/clsx): Construct className strings conditionally
      - [React](https://reactjs.org/): UI framework
      - [Tailwindcss](https://tailwindcss.com/): CSS

   - ### Only used in the development:

      - [TypeScript](https://www.typescriptlang.org/): Type-safe javascript
      - [Eslint](https://eslint.org/): Lint code
      - [Prettier](https://prettier.io/): Code formatter
      - [Vite](https://vitejs.dev/): Build tool

## Setup Development Environment

   - ### Prerequisites

      - Git
      - Node.js v22.14.0 or higher

   - ### Clone the Project

      ```sh
      git clone xxx/project-x
      cd project-x
      ```

   - ### Install Dependencies

      ```sh
      npm install
      ```

   - ### Run Development Server

      ```sh
      npm run dev
      ```

## Build source code

   ```bash
   npm run build
   ```
